Установка PHP

Сборка для Windows и первый запуск

Не ставьте PHP отдельно

Для обучения нужен не просто PHP, а связка: веб-сервер, PHP и MySQL. Собирать её вручную на Windows — полдня на настройку расширений. Проще взять готовую сборку: XAMPP, OpenServer или Laragon. Они кладут всё в одну папку и запускаются кнопкой.

Шаг 1. Скачать и установить

Скачайте XAMPP с официального сайта, выберите PHP 8.2 или новее. Установщик спросит папку — оставьте C:\xampp. Антивирус иногда ругается на httpd.exe: это ложное срабатывание, добавьте папку в исключения.

Шаг 2. Запустить сервер

Откройте XAMPP Control Panel и нажмите Start у модулей Apache и MySQL. Оба должны стать зелёными. Если Apache не стартует — почти всегда занят порт 80.

Шаг 3. Проверить

Откройте http://localhost — увидите стартовую страницу XAMPP. Там же ссылка phpinfo(): она показывает версию, загруженные расширения и пути.

Версия PHP в консоли проверяется командой:

C:\xampp\php\php.exe -v

Шаг 4. Первый скрипт

Файлы сайта лежат в C:\xampp\htdocs. Создайте там файл index.php:

<?php
echo "Привет, мир";

Сохраните в кодировке UTF-8 без BOM и обновите http://localhost. Если видите текст вместо кода — всё работает.

Шаг 5. База данных

phpMyAdmin открывается по адресу http://localhost/phpmyadmin. Стандартный пользователь — root без пароля: это нормально для локальной машины и категорически недопустимо на хостинге.

Частые ошибки

  • Apache не запускается. Порт 80 занят Skype или IIS. Смените порт в настройках Apache или закройте программу.
  • Страница показывает код. Файл открыт как .html или сохранён вне htdocs.
  • Кракозябры вместо текста. Нет charset=utf-8 или файл сохранён в другой кодировке.
  • Не найден драйвер MySQL. В php.ini не включено расширение pdo_mysql — уберите точку с запятой в начале строки.
