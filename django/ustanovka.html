Установка Django на Windows

Python, venv, startproject, runserver

Что понадобится

Ничего кроме Python, терминала и любого редактора кода. Node.js, Docker и база данных на этом этапе не нужны: Django по умолчанию работает на SQLite, а она уже встроена.

Шаг 1. Установить Python

Качайте Python 3.11 или новее с python.org. В установщике обязательно поставьте галочку Add python.exe to PATH — без неё команда python в терминале не найдётся. Проверка: python --version и pip --version.

Шаг 2. Создать папку проекта и окружение

Виртуальное окружение изолирует пакеты проекта от системного Python. Без него версии библиотек начнут конфликтовать между проектами.

mkdir C:\projects\blog
cd C:\projects\blog
python -m venv .venv
.venv\Scripts\activate

В начале строки появится (.venv) — значит окружение активно. В PowerShell, если активация запрещена политикой, выполните один раз: Set-ExecutionPolicy -Scope Process RemoteSigned.

Шаг 3. Установить Django

pip install django
python -m django --version

Вторая команда должна вывести номер версии. Если выводит ошибку — окружение не активировано.

Шаг 4. Создать проект

django-admin startproject config .

Точка в конце важна: она создаёт файлы в текущей папке, а не во вложенной. Получится manage.py и каталог config с настройками, маршрутами и wsgi. Приложения создаются так: python manage.py startapp blog. Проект — это конфигурация, приложение — кусок функциональности.

Шаг 5. Запустить сервер

python manage.py runserver

Откройте http://127.0.0.1:8000 — увидите стартовую страницу Django с ракетой. Значит, всё работает. Полезные команды рядом: migrate создаёт таблицы, createsuperuser даёт доступ в админку /admin/.

Частые ошибки

  • python не найден. При установке не была отмечена галочка PATH. Переустановите Python или добавьте путь вручную.
  • django-admin не найден. Окружение не активировано либо установка прошла в системный Python.
  • Порт 8000 занят. Запустите на другом: python manage.py runserver 8001.
  • Кракозябры в консоли. Выполните chcp 65001 — это переключит кодовую страницу на UTF-8.
