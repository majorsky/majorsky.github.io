Как разместить код виджета WhatsApp на сайте?

Ниже — два фрагмента кода для размещения на вашем сайте:

  • Код виджета WhatsApp на языке HTML — его лучше разместить в разделе «Footer» вашего сайта.
  • Код стилей CSS виджета WhatsApp — добавьте его в таблицу стилей, чтобы кнопка закрепилась в нижнем правом углу и не перекрывала контент.

HTML-код виджета WhatsApp для сайта

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<meta http-equiv="X-UA-Compatible" content="IE=edge">
<title>Кнопка WhatsApp</title>
<link rel="stylesheet" href="https://stackpath.bootstrapcdn.com/font-awesome/4.7.0/css/font-awesome.min.css">
</head>
<body>
<a href="https://api.whatsapp.com/send?phone=ВАШ НОМЕР ВИДА 7ХХХХХХХХХХ" class="whatsapp" target="_blank" rel="noopener"> <i class="fa fa-whatsapp whatsapp-icon"></i></a>
</body>
</html>

CSS-код виджета WhatsApp для сайта

.whatsapp {
position: fixed;
width: 44px;

right: 14px;
bottom: 63px;
background-color: #25d366;
color: #FFF;
border-radius: 50px;
text-align: center;
font-size: 18px;
z-index: 100;
}

.whatsapp-icon {
margin-top: 13px;

}
